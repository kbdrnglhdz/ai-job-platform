## Principios Clave

- **Domain-Driven Design**: El modelo de dominio refleja el lenguaje ubicuo y las reglas de negocio.
- **Arquitectura Hexagonal / Por Capas**: Separación clara entre dominio, aplicación, infraestructura y presentación.
- **SOLID y DRY**: Código mantenible y sin duplicaciones.
- **Desarrollo Guiado por Pruebas (TDD)**: Pruebas primero, implementación después.
